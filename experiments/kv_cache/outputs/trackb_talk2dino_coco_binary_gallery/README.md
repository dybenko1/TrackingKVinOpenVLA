# Original Talk2DINO COCO binary gallery

Thirty COCO Object val2017 examples selected by ground-truth category-union area before model inference. Each figure compares RAW and CLEAN using the same original image, query, oracle mask, and 0.54 threshold.

See [the full report](EXPERIMENT_REPORT.md) for aggregated metrics and protocol details.
